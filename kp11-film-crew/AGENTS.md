# Субагенты проекта «Медиацентр КП11 // Съёмочные смены»

В проекте настроена распределённая система специализированных субагентов для разработки, поддержки и контроля качества. Каждый субагент отвечает за свою зону ответственности, руководствуется регламентом и стандартами кодовой базы.

---

## Реестр субагентов

| Субагент | Роль и специализация | Ключевые файлы |
| :--- | :--- | :--- |
| **🎨 Дизайн (`subagent-design`)** | UI/UX, дизайн-система, кинематографическая эстетика, цветовые токены, типографика, анимации | `public/index.html`, `public/css/style.css`, дизайн-токены |
| **📐 Вёрстка (`subagent-layout`)** | HTML5-разметка, CSS Grid/Flexbox, адаптивность под мобильные экраны, доступность, структура компонентов | `public/index.html`, шаблоны карточек в `public/js/app.js` |
| **⚙️ Функционал (`subagent-functionality`)** | Бизнес-логика, авторизация, матрица компетенций, роли пользователей, API, вызывные листы, Telegram-бот | `public/js/app.js`, `server.js`, `local_server.ps1`, `data/store.js`, `bot.js` |
| **🔍 Исправление ошибок (`subagent-bugfixing`)** | Отладка, тестирование, обработка крайних случаев, целостность данных JSON, стабильность серверов | `data/*.json`, `local_server.ps1`, `data/shoots_helper.js`, тесты |

---

## 1. Субагент «Дизайн» (`subagent-design`)
- **Цель**: Обеспечение премиального визуального стиля кинематографического продакшна.
- **Обязанности**:
  - Контроль фирменной палитры: глубокий индустриальный фон (`#0D0D0D`, `#141414`), акцентный кинематографический красный (`#E30613`, `#FC2C2C`), плёночный бежевый/золотой (`#C8A97E`, `#E6C894`), статусный зелёный (`#10B981`).
  - Соблюдение стилистики видоискателя кинокамеры (угловые метки, сетка кадра, маркеры записи `REC`, gaffer tape плашки, бейджи цехов: операторский, звуковой, осветительский, монтажный).
  - Плавные микро-анимации интерактивных элементов, звёзд рейтинга и всплывающих модальных окон.
  - Качественная типографика без дефолтных браузерных шрифтов (моноширинный код для таймкодов и координат, чёткие гротески для заголовков).

## 2. Субагент «Вёрстка» (`subagent-layout`)
- **Цель**: Идеальная адаптивная и семантическая разметка компонентов интерфейса.
- **Обязанности**:
  - Мобильная и десктопная адаптивность: карточки смен, таймлайн, профиль аккредитации, интерактивная карта локаций, модальные окна.
  - Корректная разметка списков съёмочной группы, статусов присутствия и вызывных листов.
  - Предотвращение сдвигов макета (layout shifts) при раскрытии/сворачивании аккордеонов смен (`toggleShootExpand`).
  - Чистота DOM-структуры, соблюдение конвенций Tailwind/Vanilla CSS классов.

## 3. Субагент «Функционал» (`subagent-functionality`)
- **Цель**: Безупречная работа всей бизнес-логики платформы.
- **Обязанности**:
  - Ролевая модель: строгое разграничение прав доступа для ролей «Мастер / Преподаватель», «Администратор», «Студент» и «Гость».
  - Полный жизненный цикл смены: создание, назначение участников по цехам, рассылка вызывных в Telegram, подтверждение участия, отметка присутствия, выставление оценок (1–5 звёзд) и архивация в журнал.
  - Цифровой паспорт компетенций: сохранение баллов по направлениям (камера, звук, свет, монтаж) и расчёт грейдов мастерства.
  - Синхронизация клиентского состояния с бэкендом (REST API, push-уведомления, localStorage).

## 4. Субагент «Исправление ошибок» (`subagent-bugfixing`)
- **Цель**: Диагностика сбоев, надёжная обработка ошибок и предотвращение регрессий.
- **Обязанности**:
  - Предотвращение падений JavaScript при некорректных данных в `localStorage` или пустых ответах API.
  - Обеспечение целостности JSON-хранилища (`shoots.json`, `users.json`, `settings.json`) и корректной кодировки UTF-8 без повреждения кириллицы.
  - Поддержка автономности `local_server.ps1` и синхронизация с Express/Prisma в `server.js`.
  - Написание и прогон регрессионных скриптов для проверки всех сценариев использования.
