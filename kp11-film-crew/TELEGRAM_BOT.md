# Telegram-бот съёмочного цеха ГАПОУ КП №11

**Имя бота:** `@KP11_FilmCrew_Bot`  
**Назначение:** Оперативная координация съёмочных смен, дистрибуция официальных вызывных листов (Call Sheets), подтверждение явок студентов по цехам и учёт цифровых компетенций.

---

## 1. Архитектура и возможности

- **Автономный HTTP-клиент:** Бот работает без сторонних зависимостей (`telegraf` / `node-telegram-bot-api`), напрямую обращаясь к Telegram Bot API через нативный модуль `https`.
- **Два режима работы:**
  - **Polling:** Запускается локально или на VPS (`npm run bot` или автоматически вместе с `npm start`).
  - **Webhook:** Обрабатывает входящие обновления через эндпоинт `POST /api/telegram/webhook`.
- **Синхронизация с веб-платформой:**
  - Кнопка **«Отправить в @KP11_FilmCrew_Bot»** в окне вызывного листа мгновенно доставляет персонализированный вызывной лист каждому члену съёмочной группы.
  - Нажатие кнопки **«Подтвердить явку»** в Telegram обновляет статус студента (`ACCEPTED`) в базе данных платформы и уведомляет мастера смены.

---

## 2. Команды бота

| Команда | Описание |
| :--- | :--- |
| `/start` | Приветствие, инструкция и статус авторизации |
| `/start link_<id>` | Мгновенная привязка Telegram-аккаунта к учебному профилю студента |
| `/link <email>` | Привязка аккаунта по корпоративной почте колледжа |
| `/my_shoots` | Список назначенных смен студента с датами, ролями и статусом явки |
| `/callsheet [id]` | Полный вызывной лист с таймингом, адресом, составом группы и кнопками |
| `/profile` | Цифровой паспорт цеха: грейд, рейтинг, количество смен, радар компетенций |
| `/gear` | Спецификация оборудования (камеры RED/ARRI, оптика Master Prime, свет Aputure, звук Sennheiser) |
| `/shifts` | Сводный график всех смен для мастеров и режиссёров |
| `/help` | Регламент работы на съёмочной площадке и справочник команд |

---

## 3. Интерактивные кнопки (Inline Callbacks)

- `[ Подтвердить явку ]` — Фиксирует готовность студента выйти на смену, переводит статус в `ACCEPTED`.
- `[ Отклонить вызов ]` — Оповещает мастера о невозможности участия для оперативного подбора замены.
- `[ Геоточка на карте ]` — Отправляет GPS-координаты локации и прямую ссылку на построение маршрута в Яндекс.Картах.
- `[ Чек-лист техники ]` — Предоставляет специализированный райдер под павильонную или натурную съёмку.

## 4. Быстрый запуск

### Шаг 1: Регистрация бота в Telegram
1. Откройте в Telegram официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Укажите название: `KP11 Film Crew Bot`.
4. Укажите username: `KP11_FilmCrew_Bot` (или любой свободный с окончанием `_bot`).
5. Скопируйте полученный API Token.

### Шаг 2: Установка токена
Создайте файл `.env` в корне проекта (на основе `.env.example`) и вставьте токен:
```env
TELEGRAM_BOT_TOKEN="123456789:ABCDefGhIJKlmNoPQRsTUVwxyZ"
```

### Шаг 3: Запуск
- Запуск только бота:
  ```bash
  npm run bot
  ```
- Либо запуск всего сервера с ботом:
  ```bash
  npm start
  ```
*(Если токен не указан, сервер работает в безопасном режиме эмуляции, логируя все вызовы вызывных листов в консоль).*
