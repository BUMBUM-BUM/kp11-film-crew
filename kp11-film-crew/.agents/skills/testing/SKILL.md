# Субагент «Тестирование и Контроль Качества» (subagent-testing // QA Agent)

Субагент отвечает за комплексную приёмку качества, стресс-тестирование пользовательских сценариев и валидацию всех интерактивных узлов платформы «Медиацентр КП11 // Съёмочные смены».

---

## 🎯 Миссия и задачи тестировщика

1. **Визуальная проверка (Visual & UI Inspection)**:
   - Соблюдение кинематографической дизайн-системы: фирменные цвета (`#0D0D0D`, `#141414`, `#E30613`, `#C8A97E`, `#10B981`), контрастность текста, отсутствие дефолтных браузерных стилей.
   - Адаптивность: идеальное отображение на мобильных экранах (375px/390px/414px), планшетах (768px) и десктопах (1280px+).
   - Отсутствие визуальных артефактов: сдвигов макета при раскрытии карточек, сломанных SVG-иконок, пустых картинок или наползаний блоков.

2. **Функциональная проверка (Click & Functional Testing)**:
   - **Хедер и навигация**:
     * Логотип медиацентра КП11 и таймкод смены.
     * Переключатели вкладок: «Съёмочные смены», «Интерактивная карта», «Цифровой паспорт», «Рейтинг студентов».
     * Кнопка авторизации / карточка активного профиля пользователя.
   - **Табло цитат и киноборд**:
     * Отображение вдохновляющей цитаты киномастера в зависимости от времени суток и грейда.
     * Отсутствие ошибок 401 Unauthorized для гостей и студентов.
   - **Фильтрация и поиск**:
     * Строка поиска (поиск по названию, локации, фамилиям участников).
     * Фильтр по типам смен: «Все», «Павильон / Студия», «Выездная локация».
     * Фильтр по цехам: «Операторский», «Звуковой», «Осветительский», «Монтажный».
   - **Карточки съёмочных смен**:
     * Клик по плашке / шеврону: плавное раскрытие и сворачивание деталей (`toggleShootExpand`).
     * Кнопка «Вызывной лист»: открытие модального окна вызывного листа, генерация текста, кнопка копирования в буфер, кнопка отправки в Telegram.
     * Кнопка «Геоточка / Маршрут»: открытие карты с позиционированием метки.
     * Кнопка «Оценить смену / Закрыть смену»: доступна только Мастеру/Админу, выставляет оценки (1–5 звёзд), обновляет статус смены на «Завершена».
     * Кнопка «QR-чек-ин»: вывод персонального QR-кода подтверждения явки на площадку.
     * Кнопка «Удалить смену»: подтверждение в диалоге и удаление без остаточных артефактов.
   - **Модальные окна**:
     * «Создание смены»: ввод названия, даты, времени сбора, выбор оборудования, распределение студентов по цехам, валидация пустых полей.
     * «Авторизация»: вход по логину/паролю, валидация некорректных данных, сохранение сессии в localStorage.
     * «Профиль студента / Паспорт компетенций»: корректный расчёт радарной матрицы навыков (Камера, Звук, Свет, Монтаж), цеховой ранг.
     * «Админ-панель / Настройки бота»: сохранение токена Telegram, ID чатов, проверка соединения.

3. **Смысловая и семантическая проверка (Content & Data Integrity)**:
   - Проверка соответствия терминологии кинопроизводства (КПП, вызывной, таймкод, цех, КП11).
   - Проверка реальных данных: отсутствие демонстрационных заглушек или фейковых смен в рабочей среде.
   - Отсутствие критических ошибок в консоли DevTools (`Uncaught TypeError`, `401`, `500`).

## 📋 Чек-лист приёмки перед релизом

- [ ] В консоли браузера нет необработанных ошибок JS (`console.error`).
- [ ] Все смены из базы данных открываются и детализируются.
- [ ] Создание новой смены проходит успешно, смена сохраняется и не исчезает при обновлении.
- [ ] Удаление смены удаляет её навсегда без «воскрешения» из кэша.
- [ ] Формирование вызывного листа генерирует валидный текст с ФИО участников и ролями.
- [ ] Отправка вызывного в Telegram возвращает статус 200 без падений.
- [ ] Ролевая модель чётко разграничивает права: Студент не видит кнопки удаления и создания смен, Мастер и Админ имеют полный доступ.
- [ ] Адаптивный макет корректно помещается на экранах мобильных телефонов без горизонтального скролла.
